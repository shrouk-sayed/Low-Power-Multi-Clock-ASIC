# Low-Power Multi-Clock ASIC Design

## Project Overview

This project focuses on the design and implementation of a Low-Power Multi-Clock ASIC system using RTL design and digital ASIC implementation methodologies.

The project covers the main stages of the ASIC design flow, from RTL development and verification to synthesis, timing analysis, DFT, gate-level simulation, and physical design.

## Project Contents

The repository is organized into the following directories:

- **RTL/** – Verilog RTL source files.
- **Testbench/** – Testbench files for functional verification.
- **Constraints/** – Design constraints for synthesis and implementation.
- **Scripts/** – Automation and flow scripts.
- **GLS/** – Gate-Level Simulation files, including netlists and SDF files.
- **Reports/** – Design reports, including area and clock reports.
- **Documentation/** – Architecture diagrams and project screenshots.

## Design Flow

The project includes the following design stages:

1. RTL Design
2. Functional Verification
3. Logic Synthesis
4. Design for Testability (DFT)
5. Gate-Level Simulation (GLS)
6. Static Timing Analysis (STA)
7. Physical Design and Layout Generation

## RTL Design

The RTL implementation includes a parameterized ALU module written in Verilog, with configurable input, function, and output widths.

## Verification and Analysis

The repository contains verification-related files and implementation reports to document the design flow and its results.

## Physical Design

Physical design results and layout screenshots are included in the Documentation directory.
